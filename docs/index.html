Abstract

The integration of Unmanned Aircraft Systems (UAS) into Very Low Level (VLL) airspace, including urban air logistics and emergency response applications, introduces strong safety and verification requirements for Innovative Air Mobility (IAM). Existing planners and controllers can provide individually feasible actions but lack mechanisms to enforce grid occupancy exclusion and logical state consistency at runtime. Formal model-based approaches offer rigorous design-time verification, but often provide limited support for bidirectional cyber-physical synchronisation during operation. The main problem is to represent airspace topology and UAS state in one formal model, check candidate actions before execution, and keep the model synchronised with UAS state.

We present an end-to-end runtime-assured executable digital twin in which airspace occupancy, adjacency, UAS state, battery level, and communication status are represented as a bigraphical reactive system; candidate movements are admitted only when they satisfy reaction-rule preconditions, otherwise the system waits, replans, or triggers fail-safe behaviour. Model checking validates grid occupancy exclusion and landing-state consistency. Hybrid flight experiments demonstrate discrete vertex-occupancy exclusion for real and simulated UAS under the stated abstraction, achieving zero grid co-occupancy violations through the runtime gate, and verified fail-safe recovery under battery and communication faults.

Contributions

  • We define a unified bigraph modelling method for UAS flight operations in discretised 3D airspace, integrating airspace topology, occupancy, adjacency, mission phase, battery state, and communication state into a single executable runtime representation.
  • We develop a pre-execution verification and fail-safe mechanism based on bigraph rewriting. Candidate movements and state transitions are executed only when their reaction-rule preconditions hold, enforcing grid occupancy exclusion and logical consistency before actuation.
  • We implement the framework as an end-to-end runtime assurance system with ROS-based UAS execution, model synchronisation, and operator monitoring. We evaluate it through bounded model checking, real Crazyflie flights, and Webots simulation.
